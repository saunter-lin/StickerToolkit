# Sticker Toolkit v1.3.1

## Added

- 新增可選的 Background to Alpha 功能，在切割前移除與 4×4 合集畫布外部連通的固定純色背景。
- 自動背景色偵測使用角落小區塊中位數與邊界多數色；自動偵測不成立時使用手動色碼。
- Desktop GUI 提供啟用開關、自動偵測、偵測色碼、手動顏色選擇器，以及預設為 `3`、範圍 0～30 的容差設定。

## Compatibility

- 功能預設關閉，v1.3.0 的 LINE、WeChat、Preview、ZIP 與輸出目錄規格維持不變。
- 不包含 AI 去背、GIF 或 APNG 支援。
- 最適合固定純色、無漸層、無陰影、無紋理的背景；若原圖已是真正透明 PNG，無需啟用。

## Recommended source background

AI 生圖可使用淺米黃色 `#FFF8EC` 作為固定純色背景。預設容差維持為 `3`：純色 PNG 建議使用 `3～5`；JPEG 或有壓縮色差的圖片可提高至 `10～15`。容差越高，越可能影響淺色細節。
