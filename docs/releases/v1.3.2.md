# Sticker Toolkit v1.3.2

## Added

- 新增「WeChat 批次單圖」輸入模式，可直接選擇並排序 16 張 PNG、JPG 或 JPEG。
- 每張批次圖片重用既有純色背景轉透明、Alpha Trim、等比例縮放與安全留白處理，再交由既有 WeChat exporter 輸出。
- 批次模式依 GUI 清單順序輸出 `01.png`～`16.png`，並以 Banner stem 建立 `{banner_stem}_wechat_sticker` 素材目錄。
- LINE main 與 WeChat cover 新增「自動產生」（預設）或「自選圖片」。

## Changed

- Desktop 採用原生 Qt QScrollArea，使用按需顯示的垂直 scrollbar、停用水平 scrollbar，並保留 1080 px 最大內容寬度與置中配置。

## Compatibility

- v1.3.1 整合圖模式仍是預設值。
- LINE、WeChat、Preview 與 ZIP 的既有格式及命名維持不變。
- 不包含 GIF、APNG、AI 去背或新的平台 exporter。

## Validation status

- 83 項自動測試、Ruff 與 Compileall 已通過。
- Windows 100%、125%、150% DPI 與封裝版啟動測試已通過。
- 正式 macOS arm64 封裝依本版本 Commit 重新建立。
