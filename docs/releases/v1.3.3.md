# Sticker Toolkit v1.3.3-dev

## Changed

- Improved tolerance for imperfect AI-generated 4×4 sticker sheets, removing likely neighboring-cell fragments while preserving legitimate sticker text, characters, and props.
- 固定 4×4 切割後，以相鄰格線兩側的 connected-component 連續性、相對面積、深入程度、接觸比例與本格主體關係建立保守的可疑分數。
- 只有高可信度的較小跨格碎片會透明化；完整文字、角色肢體與獨立小道具優先保留。

## Compatibility

- 不改變 LINE、WeChat、Preview、ZIP 或平台素材規格。
- WeChat 批次單圖模式不經 4×4 切割，因此不套用此清理步驟。
- 未新增第三方 dependency 或平台限定邏輯。

## Validation status

- 使用程式化圖片涵蓋上下／左右污染、正常靠邊內容、乾淨組圖及非典型可整除尺寸。
- 使用實際 1254×1254 AI 組圖完成 LINE＋WeChat 暫存輸出驗證；私人樣本不納入 Repository。
